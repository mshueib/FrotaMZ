# FrotaMZ

Gestão de frota e rent-a-car para Moçambique: viaturas e documentos, combustível e custos, manutenção preventiva, reservas, clientes, faturação com IVA 16% e relatórios de custo por km.

## Experimentar

Abrir `index.html` no browser (duplo clique), ou:

```bash
npm run dev
```

e ir a http://localhost:5173. Os dados de exemplo carregam sozinhos e as alterações ficam guardadas no browser.

## Continuar com o Claude Code

```bash
cd C:\FrotaMZ
claude
```

O ficheiro `CLAUDE.md` descreve a arquitetura, as regras de negócio e o roadmap, e o Claude Code lê-o automaticamente.
